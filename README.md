
# Healthcare SRE Platform

### By Arif Faheem Khan

A production-inspired Healthcare Cloud Reliability
Engineering Platform built using AWS, Kubernetes,
Terraform, Prometheus, Grafana and Python.

## Project Overview

This project demonstrates how to design, deploy,
monitor and operate a resilient cloud-native
healthcare application platform.

## Architecture

- AWS EKS
- Terraform Infrastructure as Code
- Kubernetes and Helm
- GitHub Actions and ArgoCD
- Prometheus and Grafana
- CloudWatch
- SLO / SLI / Error Budgets
- Disaster Recovery
- Incident Management Automation
- AI-Assisted Root Cause Analysis

## Engineering Objectives

1. Improve service reliability.
2. Reduce operational toil.
3. Automate infrastructure provisioning.
4. Establish measurable SLOs.
5. Improve incident detection and recovery.
6. Implement secure cloud infrastructure.
7. Test disaster recovery capabilities.
